# YOLOv5 适配目录

当前尚未实现 YOLOv5 装甲板模型适配器，未注册可训练的 `yolov5n` 模型。

后续实现需要在此目录维护 YOLOv5 专属骨干、neck 和特征路由，明确 P3/P4/P5 的通道与 stride，再连接共享装甲板检测头。数据加载可复用 `armor_pose.data`，检测头与颜色/类别/四点监督损失可复用 `armor_pose.common`。

适配器必须保持输入 `1×3×480×640`、输出 `1×21×6300` 的协议，以及独立的 4 色、9 类和 LT/LB/RB/RT 四点定义。完成实现与验证后才能注册到模型工厂；修改配置中的模型名不会生成 YOLOv5 网络。
